# Pharos Agent Arena · Docs MCP Onboarding (self-onboarding with the Developer Docs MCP only)

An honest feedback log of onboarding onto **ai.pharos.xyz** using **only** the Pharos Developer Docs MCP
(`https://docs.pharos.xyz/~gitbook/mcp`) — no external docs, search engines or community help — plus the small
read-only agent check I could build from what the docs told me.

Built for the Pharos *Season of AI · Agent Arena* task
[Docs MCP Onboarding](https://pharos-agent-arena.vercel.app/tasks/docs-mcp-onboarding).

## Files

| File | What it is |
|---|---|
| `onboard_session.py` | replays the session: each step in `session_plan.json` is one Docs MCP call (`askQuestion`, `searchDocumentation` or `getPage` only); writes `transcript.json` (verbatim answers, timings, doc links) and `transcript.md` |
| `session_plan.json` | the 15 steps (intent, tool, exact query) |
| `transcript.json` / `transcript.md` | the recorded run of 2026-10-14 22:13 UTC (answers can differ on a re-run: `askQuestion` is generated by the docs server) |
| `final_run.py` | what I built at the end: a read-only check of the hosted Chain MCP using only facts from the transcript (chain id, `/health`, USDC `totalSupply()`, `get_logs` 1,000-block cap, tool schemas vs. the Docs MCP answer, broadcasting probe) |
| `sample_final_run.txt` | its real output on Pharos mainnet, block #20,255,962 |
| `pharos_mcp.py` | minimal MCP Streamable-HTTP client (handshake, session id, 429 back-off, UTF-8 decoding of SSE) shared with my other Arena tasks |

## Run it

Python 3.10+ (tested with 3.12).

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt          # requests

python onboard_session.py                # ~2.5 min; rewrites transcript.json / transcript.md
python onboard_session.py --only 7,12    # re-ask just the steps behind Gap 1 and Gap 4
python final_run.py                      # ~20 s; add --json for machine-readable output
```

## Safety

* Read-only. No API key, no private key, no wallet, no transaction. Endpoints are HTTPS only (`pharos_mcp.py`
  refuses plain HTTP except localhost); `getPage` steps are restricted to `https://docs.pharos.xyz/…`; queries are
  length-checked.
* `final_run.py` probes whether the hosted `send_raw_transaction` is enabled with the single byte `0x00`, which is
  not a transaction and is rejected during decoding — nothing can be broadcast.
* The Docs MCP `sendFeedback` tool is never called (it would message the docs team); the suggested fixes are in the
  log for a human to submit.
