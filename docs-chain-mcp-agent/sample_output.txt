Multicall3 is listed as a Pacific Mainnet canonical contract at `0xca11bde05977b3631167028862be2a173976ca11` in [Canonical Contracts](https://docs.pharos.xyz/getting-started/canonical-contracts).
   
   * **Parameter — `addr`:** The EVM address whose native PROS balance is queried.
   * **Return — `uint256 balance`:** The balance as an integer in **wei**, not a human-formatted PROS amount.
   * **Conversion:** Pharos uses **18 decimal places**: `1 PROS = 10^18 wei`. Divide the returned value by `10^18` to express it in PROS. See [Get PROS Gas](https://docs.pharos.xyz/getting-started/get-pros-gas).
   
   It is a read-only balance query; using `eth_call` executes a message call without creating a transaction, as described in [JSON-RPC API Methods](https://docs.pharos.xyz/api-and-sdk/json-rpc-methods).
